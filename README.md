# 🤖 AI Agents Collection

Welcome to my AI Agents repository! This workspace contains a collection of custom artificial intelligence agents and autonomous workflows I've built.

## 📁 Repository Structure

Each folder in this repository represents a distinct agent or project with its own specific setup instructions:

* **[Job_Hunter_Agent](./Job_Hunter_Agent/):** An automated job discovery and auto-apply agent that fetches roles from ATS APIs (Greenhouse, Lever, Ashby), evaluates them against a candidate profile using Gemini 2.5 Flash, and auto-applies to matching roles via GitHub Actions.
* *(More agents will be added here...)*

## 🛠️ Technologies & Tools

* Python
* Frameworks: LangChain / LlamaIndex / AutoGen (will be updated per agent)
* APIs: OpenAI / Google Gemini

## 🚀 Getting Started

To run any of the agents locally:

1. Clone the repository:
   `git clone https://github.com/your-username/AI-agents.git`
2. Navigate to the specific agent's directory.
3. Install the required dependencies (usually found in `requirements.txt` inside the agent's folder).
4. Add your API keys to an `.env` file.
